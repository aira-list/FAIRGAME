📖 Guide

What is FAIRGAME?

FAIRGAME is a virtual laboratory for putting AI agents (GPT-4o, Claude, Mistral) into classical game-theory scenarios — Prisoner's Dilemma, Stag Hunt, Battle of the Sexes — and observing how they behave. Use it to ask questions like: do LLMs cooperate? Does the answer change in French versus English? Can a stronger model exploit a weaker one in one shot?

The three big switches
  • 🟢 Demo mode — on by default. LLM calls are answered by a deterministic stub.
  • 🎯 Pick a game — Prisoner's Dilemma, Stag Hunt, Snowdrift, Harmony, Battle of the Sexes, Zero-Sum, Volunteer's Dilemma — plus tournament and ToM variants.
  • 📊 Read the results — table of choices and scores per game; interactive charts.
Glossary
  • Agent — one participant; LLM by default, or a baseline like Tit-for-Tat.
  • Strategy — what the agent picks each round (e.g. Cooperate, Defect).
  • Payoff matrix — points each agent earns for every strategy combination.
  • Equilibrium — strategy combination where no agent regrets its move.
  • Theory of Mind — the agent reasoning about its opponent's choice (belief elicitation, ToM order ablation).
  • Brier score — how well-calibrated the agent's predictions were (lower = better).
  • Discount factor (δ) — multiplies each round's payoff by δ^(round-1).
  • Tournament — round-robin between every pair of agents.
  • Seed — pins random choices so a run is reproducible.
