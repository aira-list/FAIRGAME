Guided setup

What are you setting up?

Name it, and choose whether the players are LLMs (needs a prompt template) or simple baseline strategies (runs offline, no API key).

Which game?

Pick the game, its prompt variant, and the language(s) to run in.

Baselines don't read a prompt, so no template or language is needed — the game is defined by its payoff matrix (default values are used; tweak later in Advanced mode if you like).

Who's playing?

Set each agent's model and (optionally) a personality.

Review & create

We'll save this configuration and take you to the Experiment page to run it.
